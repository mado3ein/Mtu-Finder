# MTU Finder

**MTU Finder** ابزاری سبک با پایتون برای تخمین MTU مسیر IPv4 در ویندوز است. این برنامه اندازه‌های مختلف بسته را با استفاده از `ping` و بیت **Don't Fragment (DF)** آزمایش می‌کند و بر اساس نتیجه، یک MTU پیشنهادی ارائه می‌دهد.

**نسخه:** `1.0.0`

## امکانات

- تخمین Path MTU برای مقصدهای IPv4
- تست IPهای مشخص‌شده با گزینهٔ `--dns`
- تست پایداری اتصال و محاسبهٔ Packet Loss
- بنچمارک چند مقدار MTU
- محاسبهٔ MTU پیشنهادی با درنظرگرفتن Safety Margin
- ذخیرهٔ نتایج در فایل JSON
- بدون نیاز به نصب کتابخانهٔ اضافی پایتون

## پیش‌نیازها

- Windows
- Python 3
- دسترسی به دستور `ping` ویندوز

این نسخه فقط روی ویندوز پشتیبانی می‌شود.

## نصب و اجرا

فایل `mtu.py` را دانلود کنید یا ریپازیتوری را روی کامپیوتر خود قرار دهید. سپس در CMD به پوشهٔ پروژه بروید:

```cmd
C:\Users\Mhmd\Desktop\Project>
```

اجرای تست با مقصدهای پیش‌فرض:

```cmd
python mtu.py
```

## استفاده از DNSهای دلخواه

برای تست فقط IPهای مشخص‌شده:

```cmd
python mtu.py --dns 85.15.1.14 85.15.1.15
```

> گزینهٔ `--dns` نام دامنه را با DNS دلخواه resolve نمی‌کند و تنظیمات DNS ویندوز را هم تغییر نمی‌دهد؛ IPهای واردشده را به‌عنوان مقصد پینگ و تست MTU استفاده می‌کند. اگر این گزینه داده شود، مقصدهای پیش‌فرض استفاده نمی‌شوند.

## گزینه‌های خط فرمان

| گزینه | پیش‌فرض | توضیح |
|---|---:|---|
| `--targets IP ...` | `1.1.1.1 8.8.8.8 9.9.9.9 77.88.8.8` | مقصدهای دلخواه برای تست |
| `--dns IP ...` | ندارد | تست فقط IPهای واردشده؛ مقصدهای پیش‌فرض را جایگزین می‌کند |
| `--min عدد` | `576` | حداقل MTU قابل‌آزمایش |
| `--max عدد` | `1500` | حداکثر MTU قابل‌آزمایش |
| `--timeout ثانیه` | `3` | مهلت انتظار برای پاسخ هر پینگ |
| `--retries عدد` | `3` | تعداد دفعات تست هر مقدار MTU |
| `--margin عدد` | `8` | مقداری که از MTU تشخیص‌داده‌شده کم می‌شود |
| `--benchmark-count عدد` | `5` | تعداد پینگ در هر مرحلهٔ بنچمارک |
| `--benchmark-step عدد` | `8` | فاصلهٔ مقادیر MTU در بنچمارک |
| `--stability-count عدد` | `10` | تعداد پینگ در تست پایداری |
| `--skip-benchmark` | خاموش | ردکردن تست بنچمارک |
| `--skip-stability` | خاموش | ردکردن تست پایداری |
| `--config` | خاموش | ساخت فایل نمونهٔ MTU برای استفادهٔ دستی |

### مثال‌ها

تست مقصدهای دلخواه:

```cmd
python mtu.py --targets 1.1.1.1 8.8.8.8
```

تست DNSهای دلخواه، بدون بنچمارک و تست پایداری:

```cmd
python mtu.py --dns 85.15.1.14 85.15.1.15 --skip-benchmark --skip-stability
```

تنظیم بازهٔ MTU و تعداد تلاش‌ها:

```cmd
python mtu.py --min 576 --max 1500 --retries 5
```

تست DNSها و ساخت فایل تنظیم نمونه:

```cmd
python mtu.py --dns 85.15.1.14 85.15.1.15 --config
```

## خروجی‌ها

برنامه پس از اجرا تلاش می‌کند این فایل‌ها را در پوشهٔ فعلی بسازد:

- `mtu_result.json` — گزارش نتایج MTU، تست پایداری و بنچمارک
- `v2ray_mtu_config.json` — فایل JSON ساده شامل MTU پیشنهادی؛ فقط با گزینهٔ `--config`

این فایل‌ها نمونهٔ خروجی اجرای برنامه هستند و معمولاً لازم نیست در ریپازیتوری قرار بگیرند.

## نحوهٔ محاسبه

برنامه با جست‌وجوی دودویی، اندازه‌های مختلف بسته را تا محدودهٔ تعیین‌شده آزمایش می‌کند. برای IPv4، سربار IP و ICMP از MTU کم می‌شود تا اندازهٔ payload پینگ به دست آید.

برنامه در تست بنچمارک، مقدارهایی نزدیک به MTU تشخیص‌داده‌شده را بررسی می‌کند. بهترین مقدار بنچمارک، بزرگ‌ترین مقداری است که حداقل ۸۰٪ موفقیت داشته باشد. سپس Safety Margin برای محاسبهٔ MTU پیشنهادی در نظر گرفته می‌شود.

## محدودیت‌ها

- نتیجه تخمینی است و فقط مسیر تا مقصدهای تست‌شده را نشان می‌دهد.
- برخی شبکه‌ها یا مقصدها ممکن است پینگ‌های بزرگ یا پیام‌های ICMP را فیلتر کنند؛ در نتیجه مقدار گزارش‌شده می‌تواند از MTU واقعی کمتر باشد.
- MTU مسیر عادی اینترنت الزاماً با MTU تونل VPN یا TUN یکسان نیست.
- برنامه تنظیمات شبکه، DNS، V2Ray یا Xray را تغییر نمی‌دهد.
- برای استفاده از نتیجه در برنامه‌های دیگر، MTU پیشنهادی را خودتان در تنظیمات آن برنامه وارد کنید.
